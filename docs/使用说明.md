# 麦门凑单大师 使用说明

> 说一句「三个人一百块，到店自取，上海人民广场」，它会读取麦当劳门店的实时菜单和你账户里的可用券，算出三套最划算的方案。你选好、确认后，直接进入麦当劳 App 付款。

本文分两部分：

- **第一部分：点餐的人看**。用手机或电脑打开页面，用语音点餐、付款。
- **第二部分：部署的人看**。怎么配置 Token、启动服务、部署到 Render，以及命令行工具的用法。

---

## 第一部分：语音点餐

### 1. 使用前准备

| 准备项 | 说明 |
|---|---|
| 页面链接 | 由部署的人提供，形如 `https://xxx.onrender.com/?k=口令`。链接里的 `k` 是访问口令，**不要转发给不认识的人**。 |
| 麦当劳 App | 手机上安装好，并用**下单账户的手机号**登录（默认是服务器 Token 对应的账户；在设置页换了自己的 Token，就用自己的手机号）。App 登录的账号不一致的话，找不到订单，也付不了款。 |
| 支付宝 App | 在麦当劳收银台选支付宝后会跳到支付宝付款。想用微信支付的话，需要装微信。 |
| 配送地址 | 只有外送需要。程序默认用麦当劳账户里的**第一个**配送地址，请先在麦当劳 App 里添加好。 |
| 浏览器 | 手机用**系统自带浏览器**（华为浏览器、Chrome、Safari 等），**不要在微信、QQ 里直接打开**，否则付款时进不了收银台。 |
| 麦克风 | 浏览器询问麦克风权限时选「允许」。 |

### 2. 一次完整的点餐

1. **打开页面**：用浏览器打开链接。如果页面顶部出现黄色提示「微信里打不开麦当劳 App 的收银台」，说明是在微信里打开的，请点右上角 **···** → **在浏览器打开**。
2. **开始对话**：点页面中间的红色话筒按钮，右上角状态变成「**通话中**」后直接说话。
3. **说出需求**，比如：
   - 「三个人一百块，到店自取，上海人民广场」
   - 「两个人六十块，外送」
   - 「四个人一百五，不吃牛肉，不要辣，饮料就不要了」
4. **听方案**：它会说「好的，我算一下，稍等」，十几秒后念出三套方案，屏幕上同时显示方案卡片（餐品、到手价、人均、热量、比单点省多少）。
5. **选方案**：说「就要第二个」，或者直接点方案卡片上的「**选这个**」。到店自取时，它会问你堂食还是外带。
6. **确认下单**：屏幕上弹出确认卡片，核对餐品和价格，点「**确认下单**」。**只有你亲手点了这个按钮，才会真正下单**，语音说「下单」不会直接下单。
7. **付款**：下单成功后，手机会直接打开麦当劳 App，进入这笔订单的收银台。选**支付宝**，在支付宝里完成付款。
   - 如果页面停在了「**去支付**」按钮，点一下即可。浏览器只允许点击后几秒内自动跳转，下单慢了就需要手动点。
   - 在电脑上下单时，页面会显示二维码，用手机扫码打开麦当劳 App 付款。
8. **查进度**：付完款可以问「订单好了吗」，它会查询订单状态并告诉你。

### 3. 它能听懂哪些条件

| 条件 | 是否必须 | 怎么说 |
|---|---|---|
| 人数 | 必须 | 「三个人」，支持 1~20 人 |
| 取餐方式 | 必须 | 「到店自取」或「外送」 |
| 城市和地点 | 到店自取时必须 | 「上海人民广场」，会自动选最近的营业门店 |
| 预算 | 会问一句 | 「一百块」；说「不限」也可以。外送的预算包含配送费和打包费 |
| 小食 / 饮料 | 可选，默认都要 | 「不要小食」「饮料就不要了」 |
| 忌口 | 可选 | 牛肉、猪肉、鱼、辣、咖啡 |
| 不想要的餐品 | 可选 | 「不要麦旋风」 |
| 口味丰富 | 可选 | 「口味丰富一点」，同一款餐品最多点人数的一半 |
| 堂食 / 外带 | 到店自取下单时 | 「堂食」「外带」 |
| 外送备注 | 可选 | 「备注放门口」，最多 50 字 |

### 4. 三套方案是什么意思

| 方案 | 含义 |
|---|---|
| 💰 最省钱 | 保证每人都有主食（默认还有小食和饮料），到手价最低 |
| 🍗 吃最饱 | 预算内总热量最高 |
| 🏷 最超值 | 比单点省下的比例最高 |

所有价格都经过麦当劳官方 `calculate-price` 实时校验，是真实的到手价。带「随单购麦金卡优惠」的套餐按不买卡的实际价格计算；账户里有可用券时，会自动比较用券后的价格。

### 5. 页面上的按钮

| 按钮 | 作用 |
|---|---|
| 红色话筒 | 开始语音对话 |
| 静音 | 暂时不收你的声音 |
| 我说完了 | 说完话它没反应时点一下，让它开始回答 |
| 结束 | 结束本次对话 |
| 播报时不收音 | 默认开启。用外放时防止把它的声音录进去；戴耳机时可以关掉，随时插话打断它 |
| 右上角齿轮 | 打开设置页，更换 MCP Token（见下一节） |
| 方案卡片上的「选这个」 | 不用开口，直接选这套方案 |
| 确认卡片上的「确认下单」 | 真正下单，下单前请核对 |

### 6. 设置：换成自己的麦当劳账户

默认用部署者配置的麦当劳账户下单。想用自己的账户（自己的券、自己的地址、订单记在自己名下），可以换成自己的 MCP Token：

1. 在电脑或手机上打开 https://open.mcd.cn/mcp ，用手机号登录 → 右上角「控制台」→「激活」→ 同意协议 → 复制 Token。
2. 回到点餐页面，点右上角**齿轮** → 粘贴 Token → 点「**校验并保存**」。
3. 看到「✓ 已保存，账户里有 N 个配送地址」就成功了。Token 无效或过期会提示原因，不会保存。

说明：

- 新 Token **只保存在当前这台设备的浏览器里**，只对你自己的对话生效，不会影响服务器默认设置和其他人。
- 对话进行中更换会立即生效。因为换了账户，之前的方案会作废，需要重新说一遍需求。
- 点「**恢复默认**」可以改回默认账户。换浏览器、清除浏览器数据或使用隐私模式时，也会回到默认账户。
- 换了 Token 之后，麦当劳 App 也要登录这个 Token 对应的手机号。

### 7. 付款须知

- 本项目**不经手任何付款**，钱是在麦当劳 App 和支付宝里付的。
- **支付方式需要在收银台手动选择**：麦当劳没有提供预先指定支付方式的接口，所以收银台里选支付宝这一步需要自己点。收银台可能会记住上次的选择，以实际情况为准。
- 浏览器第一次拉起麦当劳 App 时可能会询问「是否允许打开」，请选允许（可以勾选「始终允许」）。
- 下单后请尽快付款。没付款的订单按麦当劳 App 的规则处理，可以在 App 的「订单」里找到继续支付。

### 8. 常见问题

**点「去支付」后跳到「麦当劳MCP 最后一步完成下单」页面，进 App 后也没有收银台**
说明是在微信内置浏览器里打开的。微信会拦截直接打开 App 的链接，只能走麦当劳官方跳转页，而这个页面不会把订单带进 App。请用系统浏览器重新打开页面；已经下好的单，去麦当劳 App 的「订单」里支付。

**点了「去支付」没反应，或提示打不开**
确认已安装麦当劳 App，并且浏览器允许「打开外部应用」（部分浏览器要在设置里开启）。2 秒内没拉起 App 时，页面会自动跳到麦当劳官方跳转页兜底。

**麦当劳 App 里找不到这笔订单**
App 登录的手机号和下单用的 Token 不是同一个账户。看一下设置页「正在使用」的是哪个 Token。

**它听不到我说话 / 没有声音**
确认页面是 `https://` 打开的，麦克风权限已允许，手机没开静音。说完它没反应时点「我说完了」。

**说完需求它说没有方案**
预算太低或条件太多。可以提高预算、去掉小食或饮料，或者减少忌口再试。

**页面打开很慢**
免费部署的服务闲置一段时间会休眠，第一次打开要等几十秒唤醒，之后就快了。

**提示「无法连接到本地服务…访问口令正确」或设置页提示「访问口令不正确」**
链接里的 `k=…` 缺失或不对，向部署的人要完整链接；也可能是服务没在运行，或部署者重启后口令变了。

### 9. 安全提示

- 持有带口令链接的人，可以用链接对应的麦当劳账户发起下单（仍需在屏幕上手动确认），请只发给信任的人。
- 自定义 Token 保存在你的浏览器里，不要在公用电脑上保存自己的 Token；用完可以点「恢复默认」清除。
- 语音模型无法自己下单，最多只能弹出确认卡片，必须由人点击「确认下单」。

## 第二部分：部署与运行

### 10. 环境要求与配置

- **Node.js 22 或更高**。项目没有第三方依赖，不需要 `npm install`。
- **配置项**：写在环境变量里，或者写在项目根目录的 `.env` 文件里（可以从 `.env.example` 复制）。

| 变量 | 是否必须 | 说明 |
|---|---|---|
| `MCD_MCP_TOKEN` | 必须 | 麦当劳 MCP Token，申请方法见第 6 节。也是设置页里的「默认 Token」 |
| `VOLC_API_KEY` | 语音点餐必须 | 火山引擎控制台 → 豆包语音 → API Key 管理，需要开通「端到端实时语音」 |
| `VOICE_ACCESS_KEY` | 建议设置 | 访问口令，就是链接里的 `k`。不设置的话每次启动随机生成，重启后链接就变了 |
| `VOLC_VOICE` | 可选 | 播报音色 ID，默认 `zh_female_vv_jupiter_bigtts` |

### 11. 三种运行方式

| 方式 | 命令 | 谁能用 | 打开地址 |
|---|---|---|---|
| 本机 | `npm start` | 只有这台电脑 | 终端打印的 `http://localhost:8787/?k=…` |
| 局域网 | `npm run voice -- --lan` | 同一 Wi-Fi 下的电脑和手机 | 终端打印的 `https://192.168.x.x:8787/?k=…`，首次打开选「继续访问」（自签证书） |
| Render 云端 | 见第 12 节 | 任何拿到链接的人 | `https://<服务名>.onrender.com/?k=<口令>` |

局域网模式的注意事项：

- 手机打不开时，多半是 Windows 防火墙拦住了 8787 端口。第一次启动时弹出 Node.js 的防火墙提示，请勾选「专用网络」并允许。
- 公司或公共 Wi-Fi 可能开了设备隔离，导致手机访问不到电脑，可以改用手机热点。
- 电脑打开 localhost 报 SSL 错误：说明之前不带 `--lan` 启动的旧服务还在运行，结束旧的 `node src/voice/server.js` 进程后再启动。

### 12. 部署到 Render

1. 打开 Render 控制台 → **New → Web Service**，连接 GitHub 仓库 `wunllso472-cyber/mcd-coudan`。
2. Build Command 和 Start Command 保持默认的 `yarn` / `yarn start` 即可（`start` 启动的就是语音点餐服务）。也可以用仓库里的 `render.yaml` 通过 **New → Blueprint** 创建。
3. 进入服务页面，在左侧菜单 **Environment** 里添加 `MCD_MCP_TOKEN`、`VOLC_API_KEY`、`VOICE_ACCESS_KEY`。找不到这个菜单的话，可以把浏览器地址改成 `https://dashboard.render.com/web/<服务ID>/env`。
4. 保存后选择重新部署。日志里出现下面这样的内容就是成功了：
   ```
   $ node src/voice/server.js
   🍔 麦门凑单大师 · 实时语音点餐
      线上地址：https://xxx.onrender.com/?k=你的口令
   ```
5. 把这个线上地址发给要用的人。之后往 GitHub 推送代码，Render 会自动重新部署（前提是开启了自动部署）。

如果日志里出现「Application exited early」，并且执行的是 `node src/cli.js`，说明部署的还是旧版本，手动选 **Manual Deploy → Deploy latest commit**。

### 13. 命令行工具（不用语音）

```bash
# 查附近门店
node src/cli.js stores --city 上海 --near 人民广场

# 生成三套方案（到店自取）
node src/cli.js plan --people 3 --budget 100 --city 上海 --near 人民广场

# 外送（默认用账户里第一个配送地址，可用 --address-id 指定）
node src/cli.js plan --people 2 --budget 80 --delivery

# 忌口与搭配
node src/cli.js plan --people 4 --budget 150 --store 1450713 --avoid 牛肉,辣 --no-side --variety

# 下单：先预览，确认无误后加 --confirm 才会真正下单
node src/cli.js order --pick 3
node src/cli.js order --pick 3 --confirm --take-way eat-in

# 麦麦省一键领券：先预览，加 --confirm 才会领取，领完再凑单会自动用券
node src/cli.js claim
node src/cli.js claim --confirm
```

| 参数 | 说明 |
|---|---|
| `--people` | 人数，1~20 |
| `--budget` | 总预算（元），含配送费和打包费 |
| `--store` / `--city --near` / `--delivery` | 三选一：指定门店 / 自动选最近门店 / 外送 |
| `--no-side` / `--no-drink` | 每人不需要小食 / 饮料 |
| `--avoid` | 忌口：牛肉/猪肉/鱼/辣/咖啡，或 `beef/pork/fish/spicy/coffee` |
| `--exclude` | 排除名称包含关键词的餐品，逗号分隔 |
| `--variety` | 同款餐品最多点人数的一半 |
| `--json` | 输出 JSON，给 AI Agent 使用 |

### 14. 已知限制

- 支付方式不能预先指定，需要在麦当劳收银台手动选支付宝。
- 在微信、QQ 等内置浏览器里，无法直接进入麦当劳 App 收银台。
- 外送只用麦当劳账户里的配送地址，不能在页面上新建地址。
- 菜单、价格和优惠随门店和时间变化，以麦当劳官方渠道的实时结果为准。
- 本项目是麦当劳程序员节创意开发大赛的参赛作品，不是麦当劳官方产品。项目输出仅供参考，不构成营养或其他专业建议。
